# 🎓 Agentic AI Engineer Learning Path

> A structured journey from AI Agent fundamentals to production-grade autonomous organizations.

---

# 🎯 Purpose

This repository is designed as a practical, project-based learning path.

Instead of studying concepts in isolation, each skill is acquired through the implementation of real-world systems.

By following this journey, you will progressively master:

- OpenAI Agents SDK
- MCP (Model Context Protocol)
- RAG Systems
- LangGraph
- CrewAI
- AutoGen
- Evaluation Frameworks
- AI Observability
- Production AI Architectures

---

# 🧭 Learning Roadmap

| Level | Theme | Objective |
|:---:|:---|:---|
| 01 | Agent Foundations | Build and understand a single AI agent |
| 02 | Knowledge Systems | Enable agents to retrieve and reason over information |
| 03 | Tool Integration | Connect agents to external systems |
| 04 | Multi-Agent Systems | Build collaborative AI teams |
| 05 | Workflow Orchestration | Design stateful agentic workflows |
| 06 | Production Engineering | Deploy reliable AI systems |
| 07 | Autonomous Organizations | Build self-organizing AI ecosystems |
